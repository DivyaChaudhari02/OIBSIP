# Oasis Infobyte - Python Web Development Internship 🚀

Welcome to my repository for the Oasis Infobyte Internship tasks. This repository contains the source code and documentation for the projects completed during this internship journey.

---

## 🎙️ Task 1: Voice Assistant
An interactive, voice-activated assistant built using Python that listens to user commands, processes them, and responds with text and speech.
* **Key Features:** Speech-to-text conversion, natural text-to-speech responses, fetches Wikipedia summaries, and opens websites like Google and YouTube.
* **Prerequisites:** `pip install speechrecognition pyttsx3 wikipedia`

---

## ⚖️ Task 2: BMI Calculator
A practical tool that helps users calculate their Body Mass Index (BMI) and categorize their health status.
* **Key Features:** Takes user weight and height input, instantly calculates BMI using standard formulas, and classifies the result into Underweight, Normal, Overweight, or Obese categories.

---

## 💬 Task 5: Chat Application
A real-time, text-based chat application built using a classic Client-Server architecture that allows communication over a local network.
* **Key Features:** Uses Python's `socket` programming, concurrent multi-terminal execution, instant message exchange, and clean network connection closure.
