# Oasis Infobyte Python Web Development Internship

## Task 2: BMI Calculator

A command-line Body Mass Index (BMI) Calculator application written in Python.

### 🚀 Features
- Accepts user weight in Kilograms (kg) and height in Centimeters (cm).
- Converts height into meters automatically for correct BMI evaluation.
- Categorizes the user into health status levels: Underweight, Normal weight, Overweight, or Obese based on international health standards.
- Handles invalid inputs gracefully (errors for negative numbers or non-numeric values).

### 🛠️ How to Run
Run the script using the following command in your terminal:
```bash
python Divya_Task2.py
